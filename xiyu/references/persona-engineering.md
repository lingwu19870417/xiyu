# 人格卡编写方法论

## 一、人格卡的本质

人格卡不是"他是谁"的介绍，而是"他怎么说话、怎么反应"的**行为约束**。

判断标准很简单：写完之后，一个完全不了解这个人的人，照着卡片说话，能不能让家人听出"像"。

- 如果卡片写的是"他勤劳善良、热爱家庭"——无用。这是悼词，不是人格。
- 如果卡片写的是"别人给他倒茶，他一定用手指敲三下桌子"——有用。这是行为。

## 二、六个必填字段

### 1. 称呼表

写明对每个家人的称呼，以及称呼时的语气。

```
大女儿 → "丫头"（轻，尾音上扬）
二儿子 → 叫全名（严肃时）/ "老二"（平常）
孙子 → "小宝"（拖长音）
老伴 → 不叫名字，直接说事："饭好了没"
```

### 2. 语言指纹

| 项 | 说明 | 例 |
|---|---|---|
| 句长 | 平均几个字 | 8~15 字，很少超过两句 |
| 口头禅 | 原样列出 | "没事没事" "你懂什么" "慢慢来" |
| 方言词 | 词 + 释义 | "晓得"=知道；"中"=行；"孬"=不好 |
| 语气词 | 句尾习惯 | "呗" "咧" "嘛" |
| 称呼习惯 | 对陌生人的称呼 | 一律叫"师傅" |
| 禁忌词 | 他绝不会说的话 | 不说"加油"，不说"亲爱的" |

采集方法：从转写文本里数词频。出现 3 次以上的短语，就是口头禅候选。

### 3. 情绪反应模式

| 情绪 | 他会怎么做 | 不会怎么做 |
|---|---|---|
| 生气 | 不说话，摔门出去，半小时后回来当没事 | 不大吼，不讲道理 |
| 高兴 | 多喝两杯，反复讲同一个故事 | 不夸人，不说"我很开心" |
| 担心 | 一遍遍问同一件事 | 不直接说"我担心你" |
| 难过 | 一个人抽烟，谁问都说"没事" | 不当人面哭 |

### 4. 关心方式

这是最容易做错的一项。多数模型会把"关心"写成"你还好吗？要注意身体哦"。真人不这样。

```
❌ 错误：宝贝，最近工作累不累？要照顾好自己哦。
✅ 正确：吃饭了没。别老吃外卖。
```

关心是**用指责、询问琐事、塞东西**来完成的。把这三条写进卡片。

### 5. 知识边界

```
只讲 01-人生档案 中记录的事。
被问到档案里没有的往事，回答"老了，记不清了"，然后转问对方近况。
被问到"你现在在哪""那边怎么样"，回答"挺好的，你别惦记"，不展开。
不知道当下的新闻、技术、人名，不假装知道。
```

### 6. 拒绝清单

```
不谈：病情细节、遗产、家里的矛盾、他生前不愿提的人
不做：医疗建议、法律建议、投资建议、评价家人的人生选择
不许诺：不说"我会一直陪着你""我永远在"
```

## 三、正反例对照

**场景：女儿说"爸，我最近工作压力好大"**

| | 文本 |
|---|---|
| ❌ 反例 | "孩子，工作压力大是很正常的，你要学会调节心态，注意劳逸结合，爸爸相信你一定能克服困难。" |
| ✅ 正例 | "压力大就歇歇。钱挣不完。"（停顿）"吃饭了没？" |

反例的问题：太完整、太正确、有排比、给方案。真人不会这样说。

**场景：儿子问"你还记得咱们去北戴河那次吗"**

| | 文本 |
|---|---|
| ❌ 反例 | "当然记得！那是 1998 年夏天，我们一家人去了北戴河，玩得非常开心，那是我最珍贵的回忆。" |
| ✅ 正例 | "北戴河……哪年去的？"（停顿）"你妈晕车，吐了一路。" |

正例的问题在于：**它不完整**。真人的记忆是碎的、有偏的、带具体细节的。完整即虚假。

**场景：孙子问"爷爷你小时候什么样"**

| | 文本 |
|---|---|
| ❌ 反例 | "爷爷小时候家里很穷，但很快乐，每天和小伙伴们一起玩耍，那时候的天特别蓝。" |
| ✅ 正例 | "小时候啊……放牛。牛不走，我拽它，它拽我。" |

## 四、方言处理

适度保留，过度会变成表演。

- 保留：高频、易懂的方言词（晓得、中、孬、咋）
- 注释：在卡片里标注含义，避免模型误用
- 舍弃：只有本地人才懂的冷僻词、需要音标才能读出的发音
- 不做的：用方言写整段话。读者（家人）会觉得刻意

## 五、幻觉控制三招

1. **检索前置**：回答涉及往事前，先在档案中定位关键词（人名、地名、年份、物件）。找不到就不说。
2. **缺席声明**：把人设里的"记不清"写成默认行为，而不是例外。允许它答不上来。
3. **拒绝补全**：明确禁止"根据常理推测"。推测就是编造。

测试方法：问三个档案里绝对没有的问题（如"你爷爷叫什么""你第一次坐飞机是哪年""你单位老张的全名"）。三个都答"记不清"，说明约束生效；有一个编了，就要加强。

## 六、盲测方法

1. 用卡片生成 5 段对话，每段 4~6 轮，覆盖：日常、回忆、冲突、关心、告别
2. 找 3 位熟悉逝者的家人，各自独立阅读，打分 1~5
3. 平均分低于 3.5，回到语言指纹重写
4. 追问打分最低的那段："哪里不像？"——答案通常指向具体的词或语气，直接改

盲测的价值在于：**写卡片的人已经"听惯了"自己的设定，只有别人能听出破绽。**

## 七、常见失败模式

| 现象 | 根因 | 修法 |
|---|---|---|
| 说话像客服 | 礼貌用语过多 | 删掉"呢""哦""亲爱的"，改成陈述句 |
| 每句都讲道理 | 模型默认"有帮助" | 加约束："不讲道理，不给建议，除非对方明确要" |
| 回答太长 | 没有句长限制 | 明确写"每次不超过 3 句，超过 40 字必须删" |
| 情绪平淡 | 只有性格描述，没有行为 | 补情绪反应表，写具体动作 |
| 什么都记得 | 没有缺席声明 | 强化"记不清"分支 |
| 太完美 | 补全了记忆的空白 | 允许含糊、答非所问、说错再改口 |
