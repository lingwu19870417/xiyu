# 夕语（Xiyu）

把已故亲人的照片、音视频与文字，整理成一个能对话、记得住、说话像他的数字人格。

它不是聊天机器人，也不是"复活"。它是**用真实资料约束出来的一个说话方式**——依据生平档案回答，记不清就说记不清，会随交流积累记忆，并且始终承认自己不是本人。

---

## 功能

| 能力 | 说明 |
|---|---|
| 素材整理 | 照片、录像、语音、日记、聊天记录、亲友访谈，统一清点与转写 |
| 人生档案 | 八段结构：基本信息、时间线、家人关系、常讲的故事、说话习惯、性格、忌讳、最后的日子 |
| 人格卡 | 用行为规则而非人物小传定义"他怎么说话"，含称呼表、语言指纹、情绪反应、知识边界 |
| 对话运行 | 先检索后回答的受约束对话，支持情绪分级与危机识别 |
| 记忆成长 | 三层记忆（事实/情节/关系），对话中产生的新事实回写日志 |
| 伦理合规 | 授权确认、AI 标识、哀伤风险识别、红线清单 |

**不做**：实时视频数字人、声音克隆模型训练、对外发布、冒充在世的人。

声音与形象需要外部工具：语音可对接 GPT-SoVITS，形象可对接 Duix-Avatar。本技能负责输出对接参数，不绑定实现。

## 使用方法

### 1. 安装

把 `xiyu/` 整个目录复制到技能目录：

```
~/.workbuddy/skills/xiyu/          # 个人技能，所有项目可用
或
<项目>/.workbuddy/skills/xiyu/     # 项目技能，随仓库共享
```

重启会话后，提及"逝者""数字人""人生故事""口述史"等即可触发。

### 2. 建档（一次，约 1~2 天）

```
我父亲去年走了，我想做一个能和他说话的数字人。
资料在我电脑里，有照片、几段录像、还有一些微信语音。
```

技能会引导完成：素材清点 → 转写 → 可选访谈 → 生成人生档案 → 生成人格卡 → 盲测。

产出目录：

```
夕语-【姓名】/
├── 00-素材清单.md
├── 00-访谈-【姓名】.md
├── 01-人生档案.md
├── 02-人格卡.md
├── 03-记忆日志.md
├── 04-对话记录.md
└── 05-授权与边界.md
```

### 3. 对话（日常）

```
用夕语，以我父亲的口吻和我说话。
```

技能加载档案与人格卡，按协议运行。每轮结束自动把新事实写入记忆日志。

### 4. 维护（每周 30 分钟）

翻一遍记忆日志，删掉不实的，把确认的内容合并进人生档案。每月备份一次整个目录。

## 设计要点

**人格卡不是介绍，是约束。** 写"他勤劳善良"没有用，写"别人倒茶他用手指敲三下桌子"才有用。

**允许它记不清。** 幻觉是这个产品最致命的缺陷——编造一件逝者没做过的事，是对家人的二次伤害。因此"记不清"是默认分支，不是例外。

**允许它不完整。** 真人说话是碎的、重复的、答非所问的。每句都正确、完整、有道理，反而不像人。

**记忆必须能删。** 任何家人可以要求删除某条记忆，无需理由。什么都不会忘的数字人，会变成监控。

## 边界与提醒

- 生成内容是 AI 模拟，不是本人，也不代表其真实意愿
- 需取得近亲属知情同意，建议设 12 个月复核期
- 仅限家庭内部使用，不公开发布、不商业化
- 出现持续强烈哀伤、现实感动摇等信号时，应寻求专业帮助
- 素材请本地保存至少两份，勿依赖任何单一平台
