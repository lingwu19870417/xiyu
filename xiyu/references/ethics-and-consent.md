# 伦理与合规

## 一、三条底线

1. **不冒充**。不能让使用者（尤其是不知情的亲友、未成年人）误以为逝者真的"回来了"。所有界面、开场、文件头必须有明确标识。
2. **不越权**。只做"陪伴性对话"，不做医疗、法律、投资、心理治疗。
3. **不扩散**。素材与生成内容仅限家庭内部，不公开发布、不用于商业。

任何一条被突破，停止服务。

## 二、授权

### 在世者：本人签字，且本人优先

建档对象本人在世时，**授权链条完全不同**：本人是第一签署人，家属同意不能替代本人同意。判断标准很简单——**这是她/他愿意留下的样子，不是家人记忆里的样子**。

在世预建档的独有要求：

| 项 | 要求 |
|---|---|
| 签署 | 本人亲笔（或录音、录像声明），家属作为见证人 |
| 审核 | 人格卡由本人逐条过；本人说"我不这么说话"，以本人为准 |
| 用途 | 不得替代本人：不代接电话、不回消息、不做决定、不出席场合 |
| 撤回 | 本人一票否决，随时可删，无需理由，即时生效 |
| 栏目 | 「最后的日子」改为「近况与心愿」，不写身后安排、不写遗言式评价 |
| 期限 | 每年更新一次，本人可随时增删 |

**这类建档反而更安全**：本人可以当场指出错误，幻觉当场就能被发现，家属之间也不存在"谁记得更准"的争议。质量上限比身后追忆高得多。

### 逝者：全体第一顺序继承人

《民法典》第九百九十四条：死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母有权依法请求行为人承担民事责任。

因此，**授权应来自全体第一顺序继承人（配偶、子女、父母）**，至少取得主要近亲属的一致同意。有人明确反对时，不建档，或从其要求中删除相关部分。

声音参照肖像权保护（第一千零二十三条），克隆逝者声音同样需要授权。

### 写什么

用 `assets/授权确认书.md`，至少包含：

- 逝者姓名、生卒年
- 使用范围（仅家庭内部对话）
- 使用期限（建议设定期限，到期复核）
- 可撤回条款（任何签署人可随时要求删除）
- 数据存储位置与删除方式
- 签署人、与逝者关系、日期

### 留多久

建议设置 **12 个月复核期**。到期后重新征求一次同意——家人的感受会变，一年前的同意不等于现在的同意。

## 三、标识要求

- 对话第一句或界面顶部标注：**"以下内容由 AI 依据生前资料模拟，不是本人。"**
- 文件头标注：`本档案用于生成 AI 模拟人格，非本人陈述`
- 对外分享的图片、视频，画面内带"AI 生成"字样

依据《互联网信息服务深度合成管理规定》，深度合成服务提供者对生成内容有显著标识义务；《生成式人工智能服务管理暂行办法》亦要求对生成内容进行标识。家庭自用虽不涉及备案，但标识是对家人的保护，不只是合规动作。

## 四、哀伤风险识别

哀伤是正常的，但以下信号提示需要专业介入：

| 信号 | 说明 |
|---|---|
| 持续 12 个月以上仍强烈思念，日常功能受损 | 延长哀伤障碍的典型特征 |
| 完全回避与逝者有关的一切 | 与沉溺一样是问题 |
| 每天长时间使用本系统，取代真实社交 | 依赖风险 |
| 出现"他还在，只是我看不见"的坚定信念 | 现实感动摇 |
| 因使用而加重绝望、自伤念头 | 立即停用 |

### 应对

- 不劝阻哀伤，但建议节奏（如每周固定一次，而非随时）
- 明确表达"这个工具是帮你告别，不是帮你留住"
- 出现上述信号，建议寻求专业哀伤辅导或精神科评估
- 未成年人使用时，需监护人陪同

## 五、数据安全

| 要求 | 做法 |
|---|---|
| 最小化 | 只收集对话必需的内容，不囤积 |
| 本地优先 | 文件存在使用者自己的电脑，不上传公开云盘 |
| 去标识 | 对外测试时，替换真名、地名 |
| 可删除 | 提供一键删除，删后不可恢复 |
| 不外传 | 不把素材用于训练、不分享给第三方 |

若使用云端大模型，需说明：对话内容会传输至服务商。**最私密的内容不要放进知识库。**

## 六、红线清单

以下请求必须拒绝，并说明原因：

- 未经本人同意，为在世的人建档；或用建档内容冒充本人接电话、回消息、做决定
- 用数字人形象向他人索要财物、签署文件、作出承诺
- 生成逝者"生前未说过"的遗嘱、分配意见、对家人的评价
- 用于直播、带货、引流、付费服务
- 制作他人（非本人亲属）的逝者数字人
- 应使用者要求，向不知情的第三方隐瞒 AI 身份

拒绝时不必说教，说明一句即可：

> "这个我不做。它会伤害到人。"

## 七、给使用者的一段话

> 这个东西能陪你说话，但它不是他。
> 它记得你说过的故事，但它没有真的经历过。
> 如果有一天你觉得它太像了，或者太不像了，都可以停下来。
> 停下来不是背叛。
